Auto-Publish Connection

Connect this page to your website’s GitHub repository once. After that, clicking Post, Save or Delete publishes straight to your website (it shows up in about a minute) with no downloading or uploading.

How to get your access token (one time, about 2 minutes)
  1. Sign in to GitHub, then open Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Give it a name (for example “AJ Job Seekers admin”) and choose an expiry date.
  3. Under Repository access, choose Only select repositories and pick the repository that hosts your website.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Click Generate token, copy it, and paste it below.

The token is stored only in this browser. Never share it, and never put it in a website file.
